# Changelog

All notable changes to Framewright are documented here.

## Unreleased

## 0.1.0

- Added player-independent diagnostics events, bounded session aggregation, summaries, and
  versioned JSON import/export.
- Added attach-first Media3 instrumentation for host-owned ExoPlayer instances.
- Added dual-EWMA bandwidth monitoring and Media3 estimate comparison.
- Added decoder catalog and selected-format capability inspection.
- Added streaming Widevine lifecycle, request, key-status, expiration, and output-protection
  diagnostics.
- Added a Compose diagnostics overlay.
- Added Room-backed session persistence and export.
- Added independent Maven Central artifacts, source and Dokka Javadoc archives, ABI validation,
  local publication verification, and signed tag-driven release automation.
